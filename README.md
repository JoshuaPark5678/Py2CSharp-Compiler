 # Py2C# Compiler

 A from-scratch compiler that takes a restricted, statically-typeable subset of Python and compiles it to C#. Built in C++ with a lexer and parser (no `ast` module).

 ## Status

 Work in progress!

 ## Build

 Roadmap
 
      1. Lexer (Done)
      2. Parser (Done)
      3. Variables & static types (Done, No static types...)
      4. Control flow (if/while/for) (Done)
      5. Code Generation to c# (Done, working mvp)
      6. Functions
      7. Compile c# via .net
      8. More Data structures (lists, dicts, sets ...)
