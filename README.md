 # Py2C# Compiler

 A from-scratch compiler that takes a restricted, statically-typeable subset of Python and compiles it to C#. Built in C++ with a lexer and parser (no `ast` module).

 ## Status

 Work in progress!

 ## Build

 Roadmap
 
      1. Lexer (working proto)
      2. Parser (working proto)
      3. Variables & static types (static types will be delayed)
      4. Control flow (if/while/for) (implemented)
      5. Code Generation to c# (next step)
      6. Functions
