 # Py2C# Transpiler

 A from-scratch source-to-source compiler that takes a restricted, statically-typeable subset of Python and turns it into C#. Built in C++ with a lexer, parser (no `ast` module) and a c# code generator.

 ## Status

 Work in progress!
